PLAYER DIRECTORY — GITHUB PAGES FILES

WHAT'S INSIDE
  index.html                      the Player Directory app
  data/players.json               every player (by Player ID) and the photo that belongs to them
  assets/players/<PlayerID>.webp  one photo per player (480 x 600, cropped the same way)
  assets/players/placeholder.webp generic placeholder image
  .nojekyll                       tells GitHub Pages to serve the files as they are

HOW TO PUBLISH
  1. Unzip this file.
  2. Upload everything inside it to the top level of your GitHub Pages repository
     (GitHub website: "Add file" > "Upload files", drag the unzipped contents in,
     then "Commit changes"). Replace the old index.html if asked.
     If the repository has an older assets/headshots/ folder, data/headshots.json,
     or Player_Directory_and_Offseason_Map.html, you can delete them.
  3. Wait about a minute, then open the site. Everyone sees the same photos —
     nothing needs to be uploaded through the app.

ADDING MORE PHOTOS LATER
  Send the new photos to Claude to crop and add, or add them in the app and use
  Publish to download an updated package.

NOTE
  Photos load from the website itself. Opening index.html straight from your
  computer may show initials instead of photos.
